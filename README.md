# 🍱 Signature Bento Grid Portfolio

A modern, high-performance **Bento Grid Dashboard Portfolio** designed for **Keerthivasan R**, inspired by the dark glassmorphic engineering aesthetic.

---

## ✨ Features

- **Chassis & Bezel**: Rounded metallic chassis with subtle reflections and ambient backdrop glows.
- **Bento Grid Layout**: Asymmetric CSS Grid matching modern developer design standards (Awwwards / Dribbble trending).
- **Interactive Mouse Spotlight**: Real-time cursor spotlight reflection across each card.
- **Live Real-time Digital Clock**: Running second-by-second live clock with dynamic day indicator.
- **Dual Theme Support**: 
  - 🌙 **Cyber Dark Bento Mode** (Default)
  - ☀️ **Clean Frosted Titanium Light Mode**
  - Seamless toggle with LocalStorage state persistence.
- **Integrated Modals & Drawers**:
  - `Say Hello / Contact` modal with direct messaging and one-click email copying.
  - `Featured Projects` interactive modal with technical highlights and stack details.
  - `About Me` engineering background & philosophy overview.
- **Showcase of Real Projects**:
  - **TerraScope AI** (Milestone 1A.14 Completed AI Rock Exploration Engine)
  - **Flowbox Automation** (Self-hosted personal automation platform)
  - **ExamArena CBT** (Cross-platform testing client & Flutter application)
  - **Auto-Job-Hunter** (Telegram-integrated automation pipeline)
- **Daily Stack**: Interactive chip grid for Python, Flutter, React, PyTorch, Node.js, Docker, Tailwind, and Git.

---

## 🚀 How to Run & Preview

Simply open `index.html` directly in your browser:
```bash
open index.html
```
Or start a local preview server:
```bash
python3 -m http.server 8080
```
